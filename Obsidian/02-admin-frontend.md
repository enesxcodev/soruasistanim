# ASP.NET Core Razor / Cuba Admin

- Kapsam: `SoruHavuzu.Admin` Razor Pages/MVC + Cuba template.
- Admin UI değişikliklerinde React kurallarını uygulama.
- Backend'e dokunma; yalnızca kullanıcı açıkça backend değişikliği isterse kapsamı genişlet.
- Görsel referans için yerel `wwwroot/theme/` dosyalarını kullan.
- Düz/sade HTML yerine mevcut Cuba bileşen ve sınıflarını kullan.
- Tekrarlanan büyük UI parçalarını mevcut ViewComponent yapısına uygun tut.
- Inline `<script>`/`<style>` ekleme; mevcut layout/script yapısını kullan.
- Dekoratif, sahte veya veriye bağlı olmayan widget ekleme.
